CryptoForgeLegend is a real-time, distributed processing engine for cryptocurrency analytics on a scalable node platform.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoForgeLegend.git`
2. `cd CryptoForgeLegend`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure CryptoForgeLegend, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
